# 经典版 33 块常规布料

全部形状允许旋转、翻转。下表四项数据与独立组件参考表一致；中文名称、配色、纹理为本项目原创。`classicId` 是 ANU 衍生实现的组件标识，便于对照，不是官方名称。

## 数据来源

- [Lookout 官方组件近照：2×2 方块](https://www.lookout-spiele.de/upload/en_patchwork.html_GalleryImage.jpg)：6 纽扣、5 时间、2 收入。
- [Lookout 官方组件近照：免费六格十字](https://www.lookout-spiele.de/upload/en_patchwork.html_GalleryImage_7.jpg)：0 纽扣、3 时间、1 收入。
- [ANU COMP1140 衍生实现：完整坐标与数值](https://github.com/CACppuccino/PatchworkGame/blob/master/src/comp1140/ass2/PatchworkGame.java)。
- [ModRef 2019 研究实现：完整 ASCII 形状与数值](https://github.com/zayenz/cp-mod-ref-2019-patchwork/blob/master/code/src/patchwork/tiles.cpp)。

32 块在两份实现中四项一致。研究实现的 6 / 5 / 2 条目坐标漏了一格；本项目按官方清晰照片及 ANU 组件资料采用完整 2×2 正方形。形状坐标和数值按组件事实记录，未使用实体版美术。

## 校验

`tests/fixtures/classic-patches.json` 保存独立组件参考表，以 ASCII 记录形状。`tests/classic-patches.test.mjs` 逐块对照形状（包括旋转与翻转）、费用、耗时、收入，并验证实际购买后的覆盖格数、扣费、时间移动及收入结算。全套测试执行 `npm test`。
